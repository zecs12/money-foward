# money-foward

マネーフォワードMEから家計データ(銀行明細・証券NISA状況・クレジットカード利用明細)を取得し、
自分のパソコンの中だけで見られるダッシュボードにまとめて分析・グラフ化するためのツールです。

作業ルールは [CLAUDE.md](./CLAUDE.md) を参照してください。

## 構成

- **アカウントA**: 楽天銀行(明細)・楽天証券(NISA状況)を登録しているマネーフォワードMEアカウント
  → Playwrightで自動ログインし、データを自動取得
- **アカウントB**: セゾンカード(利用明細)を登録しているマネーフォワードMEアカウント
  → 該当月のCSVをダウンロードして取得(セゾンカードの会員サイトから手動でダウンロードし、
  このツールに取り込む)
- 取得したデータは、自分のパソコンの中に保存するデータベース(`data/money.db`)にためていき、
  Streamlit(ストリームリット)というツールで、パソコンの中だけで見られる
  ダッシュボード(ブラウザ画面)として表示する。インターネットには公開しない。

参考: [hiroppy/mf-dashboard](https://github.com/hiroppy/mf-dashboard)(ログイン処理のみ参考にしました)

## セットアップ

### 1. 必要なライブラリをインストール

```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. 認証情報を設定

```bash
cp .env.example .env
```

`.env` を開いて、アカウントAのメールアドレス・パスワードを入力してください。
`.env` は Git にコミットされません(`.gitignore` で除外済み)。

### 3. アカウントAへの自動ログインを確認(初回のみ)

```bash
python src/login_account_a.py
```

- 初回は `.env` の `MF_HEADLESS=false` のまま実行すると、ブラウザ画面が表示され、
  ログインの様子を目で確認できます。
- 2段階認証(ワンタイムコード)が求められた場合は、ターミナルの案内に従って
  マネーフォワードMEから届いたコードを入力してください(自動取得はしません)。
- ログインに成功すると、次回以降ログインをスキップできるように
  `data/account_a_auth_state.json` にセッション情報が保存されます(このファイルもGit管理外です)。

### 4. データを取得する

初回(まだ一度もデータを取得したことがない場合)は、明細を全期間分取得します。

```bash
python src/run_scrape.py --full
```

2回目以降は、直近数か月分だけ取得すれば十分です(差分更新)。

```bash
python src/run_scrape.py
```

- 楽天銀行の明細だけを取得したい場合: `python src/scrape_cash_flow.py --full`(または `--months 6` のように月数指定)
- 楽天証券のNISA状況だけを取得したい場合: `python src/scrape_portfolio.py`
- 取得したデータは `data/money.db` というファイル(データベース)に保存されます。何度実行しても、
  同じ明細が重複して増えることはありません。資産(NISA)は実行するたびに「その時点の記録」が
  追加されていくので、あとから推移を見返せます。

### 5. セゾンカードの利用明細を取り込む

セゾンカードは自動ログインではなく、CSVファイルを手動でダウンロードして取り込む方式です。

1. セゾンカードの会員サイトにログインし、該当月の利用明細CSVをダウンロードする
2. ダウンロードしたCSVファイルを `data/saison_csv` フォルダに入れる
   (フォルダが無い場合は、先に以下のコマンドを一度実行すると自動的に作られます)
3. 以下を実行する

```bash
python src/import_saison_csv.py
```

`data/saison_csv` フォルダの中にあるCSVファイルをすべて読み込みます。複数月分をまとめて
フォルダに入れておけば、一度に取り込めます。同じカード・同じお支払日のCSVを読み込み直しても、
古いデータが新しい内容に置き換わるだけで、重複して増えることはありません。

### 6. ダッシュボードで確認する

```bash
streamlit run app.py
```

自動的にブラウザが開き、`http://localhost:8501` に「楽天銀行(家計簿)」「楽天証券(NISA)」
「セゾンカード」の3つのタブが表示されます。このページはインターネットには公開されず、
自分のパソコンの中だけで完結します。ターミナルで `Ctrl + C` を押すと終了します。
